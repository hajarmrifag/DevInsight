# Proposed participant screener

Status: template for possible future interviews. No interviews have been conducted.

Do not place responses or personal information in this repository. Use an approved research system if fieldwork is authorized.

1. In the past six months, have you created, migrated, or maintained a Vite project? (Yes / No)
2. Which best describes your involvement? (Created from scratch / Migrated / Maintained / Evaluated only)
3. Approximately how many Vite setup experiences have you had? (1 / 2–5 / 6+)
4. Which environments were involved? (Personal / Education / Work / Open source; select all that apply)
5. Are you comfortable discussing your setup process without sharing employer-confidential code or data? (Yes / No)
6. Which session format is accessible for you? (Remote call / Text-based / Other approved format)

Suggested purposive mix: first-time and repeat Vite users; create and migration experiences; different operating systems. This is not a representative sample.

Exclude people who have not used Vite recently, cannot give informed consent, or would need to disclose confidential information.
